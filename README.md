# Dapur Sangkolo Landing Page

Landing page Dapur Sangkolo untuk Wanpaku Sandwich.

## Tech Stack

- Next.js (App Router, Turbopack)
- React
- Tailwind CSS
- Lucide React

## Development

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Build

```bash
npm run build
```
